01 / SUM THE PATHS, NOT THE LABELS

One transcript.
Many alignments.

A frame can repeat a label, emit a blank, or move the transcript forward. CTC adds every compatible path. Follow the sum all the way to its gradient.

Dependency-free Python. Independent scalar JavaScript. Exhaustive finite-path witnesses.

No acoustic model runs here. These are editable synthetic logits, not speech, learned representations or recognition-quality measurements.

Negative log-likelihood

Loss is a single-example sum, with no target-length or batch reduction. A null log probability, loss or gradient means a structurally impossible target. A displayed probability of zero can instead be floating-point underflow while log probability and loss stay finite.

Merge adjacent repeats first. Remove blanks second.

The highest-probability frame path need not produce the highest-mass transcript. The output table sums all paths per transcript. Canonical ranking uses 10⁻⁸-nat log-score buckets, then lexicographic index order; raw scores remain available. The reported greedy log gap uses the maximum raw transcript log score, not the rounded rank.

06 / THE CONTRACT, NOT A QUALITY CLAIM
Alignment is latent.
The limits are explicit.
This is an implementation of established Connectionist Temporal Classification, not a new algorithm. Blank-separated repeats survive collapse. Adjacent repeated target labels need an extra frame. Empty input has probability one only for the empty target. Impossible targets keep loss and gradients undefined rather than silently zeroing them.
Finite logits are bounded by 10⁶ in magnitude. Log-space recursions keep likelihood usable when ordinary probabilities underflow. Near-tie rank buckets and near-boundary floating-point comparisons remain numerical conventions, not exact real arithmetic. The inspector does not train a recognizer or establish speech, OCR, language quality, speed or production-scale results. Native JSON rejects duplicate keys; browser JSON.parse computes the parsed record without duplicate-key detection. Use synthetic data only.
